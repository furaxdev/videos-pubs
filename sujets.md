# sujets.md — quoi traiter chaque matin

## Ligne éditoriale
IA, code, cybersécurité, outils de dev : l'actu qui fait dire « attends, quoi ? » en 30 secondes. Gratuit/open source mis en avant. Pas de rumeurs, pas de clickbait mensonger.

## Choix du sujet du jour (le matin)
Le sujet doit être **récent (≤ 48 h) OU en train de faire le buzz sur les réseaux** — toujours dans le délire tech / IA.
1. Repérer le buzz : actu des dernières 24–48 h ET ce qui cartonne en ce moment — X/Twitter (tendances IA/tech), **Instagram** (Reels et hashtags tech/IA du moment : #ai #chatgpt #claude #tech #coding #cybersecurity ; comptes tech qui postent — chercher via recherche web `site:instagram.com/reel` + sujet, pages d'agrégateurs de tendances, articles « trending on Instagram » ; Instagram est souvent derrière un mur de connexion : ne rien inventer, noter « non consultable » si besoin et s'appuyer sur les autres sources), Reddit (r/technology, r/artificial, r/programming, r/LocalLLaMA), Hacker News (page d'accueil), YouTube/TikTok/Shorts tech du moment, GitHub Trending, Product Hunt, newsletters (Ben's Bites, TLDR, The Verge, Wired, Ars Technica). Noter pour chaque candidat : date, où ça buzze, signal d'ampleur (points HN, nb de reprises, vues).
2. Classer les candidats : (a) buzz/récence, (b) vérifiable sur une source primaire (communiqué officiel, rapport, dépôt GitHub, article de fond), (c) dessinable avec nos éléments (bots têtes seules, serveurs, terminal, logos, ordi), (d) pas déjà dans `daily/historique.md`, (e) pas de tragédie ni de personne privée ciblée, pas de rumeur non sourcée.
3. Prendre le n°1. Si le meilleur buzz n'est pas vérifiable, prendre le suivant — ne JAMAIS publier un fait non vérifié.
4. Rien de solide ? Dernier recours : un sujet du backlog ci-dessous, en le rattachant à l'actu si possible.
5. Inscrire dans `SOURCES.md` : pourquoi ce sujet (preuves du buzz) + faits vérifiés + liens.

## Backlog (évergreen)
- Comment fonctionne un agent IA (boucle observe → réfléchit → agit) avec un petit bot tête seule.
- Prompt injection expliquée en 30 s (un bot qui obéit au mauvais message).
- Pourquoi un LLM « hallucine » (bot qui invente une ligne de code).
- Sandbox : c'est quoi, et comment un agent peut en sortir.
- Open source vs payant : ce que Claude Code/Codex/outils gratuits remplacent.
- Une vidéo codée en 10 minutes : montrer le terminal et le résultat.
- Mots de passe / tokens exposés : comment ça se retrouve en ligne.
